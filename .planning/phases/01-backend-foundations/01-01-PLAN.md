<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → Neon dev DB | `prisma migrate dev` executes DDL against the Neon-hosted branch. Pre-flight refuses if `DATABASE_URL` contains `prod`/`production` substring. |
| future webhook sender → WebhookLog | Phase 2 consumes the `@@unique([externalId, eventType])` constraint to reject replayed webhooks (P01). |
| future notification dispatcher → Notification | Phase 2 consumes `dedupeKey @unique` to guarantee at-most-once delivery (P06). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-01 | Tampering | Webhook replay double-credit | mitigate | `@@unique([externalId, eventType])` on `WebhookLog` — Phase 2 handler catches `P2002` and 200-noops |
| T-01-01-02 | Tampering | Notification re-fire from cron/webhook concurrency | mitigate | `Notification.dedupeKey String @unique` — Phase 2 `createNotification()` upserts on dedupeKey |
| T-01-01-03 | Tampering | Accidental prod migration from dev workstation | mitigate | Pre-flight script refuses if DATABASE_URL contains `prod`/`production` substring |
| T-01-01-04 | Denial of Service | Neon migration timeout on large Block table | accept | Block row count is <1000 on the skeleton fork (A1). Pre-flight guard exits if count >1000 and escalates to 3-step pattern |
| T-01-01-05 | Information Disclosure | Block slug collides with reserved app route (`admin`, `api`) | mitigate | Reserved-word guard lands in plan 01-02 (`BLOCK_RESERVED_SLUGS`). Schema-level unique is the backstop |
| T-01-01-06 | Elevation of Privilege | Dropped orphan model breaks an unrelated route | accept | Orphan models (Product, Community, etc.) stay intact per CLAUDE.md. Diff is strictly additive |
</threat_model>
