POST /api/auth/signup       (body, 201 response)
  request:  { email: string; password: string (>=8); displayName: string (2..50); slug: string ([a-z0-9-]{3,30}) }
  response: { seller: { id, email, slug, displayName, emailVerified }, message, emailSent }
  errors:   400 Zod, 409 "Cet email est déjà utilisé", 409 "Ce nom de page est déjà pris", 409 "Ce nom de page est réservé"
  NOTE:     Does NOT set auth cookies. Does NOT accept tosAccepted. Triggers email with 6-digit code.

GET /api/auth/check-slug?slug=X
  response: { available: boolean }
  NOTE:     Rate-limited 30/min. Returns false for reserved words and taken slugs.

POST /api/auth/login
  request:  { email, password }
  response: { seller, csrfToken }
  cookies:  izy-token (httpOnly), izy-csrf
  errors:   400 Zod, 401 "Identifiants invalides", 403 "Email non vérifié" (REDIRECT to verify-email)

POST /api/auth/verify-email
  request:  { email: string; code: string (length 6) }
  response: { seller, csrfToken }
  cookies:  izy-token (httpOnly), izy-csrf (set on success — this IS a login)
  errors:   400 "Code invalide ou expiré", 429 (6 attempts per 15 min)

POST /api/auth/resend-code
  request:  { email }
  response: { message }
  NOTE:     1-minute cooldown enforced server-side. Call on 403-unverified during login.

POST /api/auth/forgot-password
  request:  { email }
  response: { message } (always 200 to avoid email enumeration)
  NOTE:     Sends a 6-digit code via email.

POST /api/auth/reset-password
  request:  { email: string; code: string (length 6); newPassword: string (>=8) }
  response: { message }
  errors:   400 "Code invalide ou expiré"

Client helpers from src/lib/api.ts:
  api<T>(path, { method, body }): Promise<T>   // auto CSRF, auto-refresh on 401
  ApiError { status, message, body }
  storeCsrfToken(token): void                   // call after login/verify-email
  clearCsrfToken(): void

AuthContext (src/contexts/AuthContext.tsx):
  useAuth() => { seller, loading, refreshSeller, logout, ... }
  NOTE: no login()/signup() methods — pages call api() directly then refreshSeller()
  NOTE: existing fetchSeller() redirects to "/login" on 401 — must be updated to "/connexion"
