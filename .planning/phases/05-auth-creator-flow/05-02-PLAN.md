Create the hook per research Pattern 2 (lines 267-324). Exports:

```ts
export type FestiveDraft = {
  title?: string;
  occasion?: "anniversaire" | "pot_de_depart" | "cadeau_commun" | "mariage_pacs" | "naissance" | "voyage" | "autre";
  goalAmount?: number;
  coverUrl?: string | null;
  description?: string;
  thankYouMessage?: string;
  endDate?: string | null;
  visibility?: "public" | "private";
  hideAmount?: boolean;
  hideDonors?: boolean;
  tosAccepted?: boolean;
  step?: 1 | 2 | 3;
  updatedAt?: string;
};

export type SolidaireDraft = Omit<FestiveDraft, "occasion"> & {
  cause?: "sante_medical" | "education" | "projet_solidaire" | "urgence" | "animaux" | "autre";
  beneficiary?: "moi_meme" | "un_proche" | "une_association";
};

export function useWizardDraft<T extends FestiveDraft | SolidaireDraft>(
  subtype: "festive" | "solidaire",
): {
  draft: T;
  setField: <K extends keyof T>(key: K, value: T[K]) => void;
  setDraft: (next: Partial<T>) => void;
  clear: () => void;
  isReady: boolean;
}
```

Implementation rules:
- Key: `cagnotte.wizard.${subtype}.draft.v1` (versioned for future schema migration)
- Uses `sessionStorage` (NEVER `localStorage` — see Pitfall 6; localStorage leaks across logout)
- SSR-safe: `isReady = false` until first `useEffect` runs client-side, `draft = {}` during SSR
- Stale check: if `draft.updatedAt && Date.now() - new Date(draft.updatedAt).getTime() > 24*60*60*1000`, clear on mount
- Every `setField` / `setDraft` updates `updatedAt = new Date().toISOString()` and writes to sessionStorage
- `clear()` removes the sessionStorage entry + resets state to `{}`
- Wrap `JSON.parse` in try/catch; on corrupt data, clear and return `{}`
- Guard: `if (typeof window === "undefined") return { draft: {} as T, setField: noop, setDraft: noop, clear: noop, isReady: false }`

**Sub-step B — `src/app/(authed)/layout.tsx`:**

Server component (NO `"use client"`). Per research Pattern 1 (lines 211-265):

```ts
import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import type { ReactNode } from "react";
import { DashboardNavbar } from "@/components/layout/DashboardNavbar";
import { BACKEND_URL } from "@/lib/api"; // or use process.env.NEXT_PUBLIC_API_URL directly

async function fetchSellerFromCookie(token: string) {
  const backendUrl = process.env.NEXT_PUBLIC_API_URL || "http://localhost:4000";
  try {
    const res = await fetch(`${backendUrl}/api/auth/me`, {
      headers: { cookie: `izy-token=${token}` },
      cache: "no-store",
    });
    if (!res.ok) return null;
    const data = await res.json();
    return data.seller;
  } catch {
    return null;
  }
}

export default async function AuthedLayout({ children }: { children: ReactNode }) {
  const cookieStore = await cookies();
  const token = cookieStore.get("izy-token")?.value;
  if (!token) redirect("/connexion?next=/tableau-de-bord");

  const seller = await fetchSellerFromCookie(token);
  if (!seller) redirect("/connexion?next=/tableau-de-bord");

  return (
    <div className="min-h-screen bg-background">
      <DashboardNavbar seller={seller} />
      <main className="container mx-auto px-4 py-6 md:py-10">{children}</main>
    </div>
  );
}
```

Details:
- `cookies()` is async in Next 16 — must `await`.
- Redirects fire BEFORE any JSX renders (no FOUC, per Pitfall 12).
- DO NOT use `api()` server-side (see Pitfall 12 + lib/api.ts line 10 reads localStorage).
- DashboardNavbar is a Phase 3 client component that accepts `seller` prop — passing it from server is fine.
- Per research Pitfall 8 (cookie refresh race), v1 uses the SIMPLE path: any 401 on `/api/auth/me` → redirect to /connexion. v2 can add client-side refresh island.
