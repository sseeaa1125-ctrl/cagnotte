<conventions>
- **No new npm deps.** Zero tolerance. `package.json` must be byte-identical before and after. That rules out: `@radix-ui/*`, `framer-motion`, `react-hot-toast`, `react-select`, `react-datepicker`, `react-dropzone`, `focus-trap-react`, `react-modal`.
- **Ring 1 import allowlist:**
  - `react` / `react-dom`
  - `lucide-react` (icons)
  - `@/lib/utils` (cn, isInAppBrowser, isTikTokBrowser)
  - `@/contexts/ToastContext` (Toast.tsx ONLY — re-export pattern)
  - Type-only imports from `react` (`React.ButtonHTMLAttributes`, etc.)
- **Ring 1 forbidden imports** (enforced by `scripts/verify-ring-purity.sh`):
  - `@/lib/api` — no fetch in primitives
  - `@/lib/useApi` — no hooks that fetch
  - `@/lib/constants` — no French labels (caller passes text as props)
  - `@/contexts/AuthContext` — no auth awareness
  - Any component from `@/components/layout/*`, `@/components/cagnottes/*`, etc. (primitives can't reach up into Ring 2)
- **Touch targets ≥ 48px:** Use `min-h-12` (= 48px) on buttons, inputs, selects. Buttons additionally use `py-3.5` minimum. Checkboxes and radios get 48×48 hit areas via padded wrapper even if the visible control is 20×20.
- **Focus rings:** Every interactive primitive uses `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2`. Do NOT use `focus:` (always on click, breaks mouse UX); `focus-visible:` is keyboard-only.
- **Mobile-first:** Base classes target 375px. Use `md:` / `lg:` prefixes for desktop upgrades. Never the reverse.
- **Component pattern:**
  ```tsx
  "use client"; // only if the primitive uses state/effects/refs
  import * as React from "react";
  import { cn } from "@/lib/utils";

  interface XProps extends Omit<React.ComponentHTMLAttributes<HTMLElement>, "className"> {
    className?: string;
    // ... other props
  }

  export function X({ className, ...props }: XProps) {
    return <element className={cn("base classes", className)} {...props} />;
  }
  ```
- **French apostrophe rule:** If a primitive renders any default French text (it shouldn't — callers pass text as props — but if it does, e.g., the password-eye screen-reader label "Afficher le mot de passe"), use JSX brace expression `{"l'instant"}` to avoid `react/no-unescaped-entities`. Do NOT disable the rule.
- **Atomic commits by batch (5 batches, not 18 commits):** Commit churn at 18 commits/plan is excessive. Batch by category:
  - Batch A (form inputs): Input + Textarea + Select + DatePicker + ImageUpload → 1 commit
  - Batch B (selection): RadioCard + Toggle + Checkbox → 1 commit
  - Batch C (action): Button → 1 commit
  - Batch D (display): Badge + Avatar + ProgressBar + KpiCard + Pagination + Tabs → 1 commit
  - Batch E (overlays): Modal + EmptyState + Toast → 1 commit
- **After each batch:** Run `bash scripts/verify-ring-purity.sh` + `npm run build`. If either fails, STOP and fix before moving to the next batch.
- **Barrel export:** Update `src/components/ui/index.ts` incrementally as each batch lands.
</conventions>

#!/usr/bin/env bash
set -euo pipefail

# ─────────────────────────────────────────────────────────────────────────
# Ring 1 purity: src/components/ui/* must not import api / useApi / constants / AuthContext.
# Exception: Toast.tsx may import @/contexts/ToastContext (it's a thin re-export wrapper).
# ─────────────────────────────────────────────────────────────────────────

r1_violations=$(grep -rE "from ['\"](@/lib/(api|useApi|constants)|@/contexts/AuthContext)" src/components/ui/ || true)

if [ -n "$r1_violations" ]; then
  echo "❌ Ring-1 purity violation in src/components/ui/:"
  echo "$r1_violations"
  exit 1
fi
echo "✅ Ring 1 pure (src/components/ui/)"

# ─────────────────────────────────────────────────────────────────────────
# Ring 2 purity: src/components/{layout,cagnottes,checkout,share,notifications,trust}/*
# may import Ring 1 + @/lib/utils + @/lib/format + @/lib/constants, but NOT api / useApi / AuthContext.
# ─────────────────────────────────────────────────────────────────────────

r2_dirs=(
  src/components/layout
  src/components/cagnottes
  src/components/checkout
  src/components/share
  src/components/notifications
  src/components/trust
)

r2_violations=""
for dir in "${r2_dirs[@]}"; do
  if [ -d "$dir" ]; then
    found=$(grep -rE "from ['\"](@/lib/(api|useApi)|@/contexts/AuthContext)" "$dir" || true)
    if [ -n "$found" ]; then
      r2_violations="${r2_violations}${found}\n"
    fi
  fi
done

if [ -n "$r2_violations" ]; then
  echo -e "❌ Ring-2 purity violation (data-fetching in composed block):"
  echo -e "$r2_violations"
  exit 1
fi
echo "✅ Ring 2 pure (composed blocks own no data)"

**`src/components/ui/Button.tsx`** (`"use client"` NOT required — no state; but `forwardRef` is recommended for form libraries)

```tsx
import * as React from "react";
import { Loader2 } from "lucide-react";
import { cn } from "@/lib/utils";

type Variant = "primary" | "outline" | "ghost" | "social";
type Size = "md" | "lg";
type SocialProvider = "google" | "apple" | "facebook" | "whatsapp" | "email";

interface BaseButtonProps {
  variant?: Variant;
  size?: Size;
  loading?: boolean;
  iconLeft?: React.ReactNode;
  iconRight?: React.ReactNode;
  fullWidth?: boolean;
  socialProvider?: SocialProvider;
  className?: string;
  children?: React.ReactNode;
}

type ButtonElementProps =
  | ({ as?: "button" } & BaseButtonProps & Omit<React.ButtonHTMLAttributes<HTMLButtonElement>, "className">)
  | ({ as: "a" } & BaseButtonProps & Omit<React.AnchorHTMLAttributes<HTMLAnchorElement>, "className">);

export type ButtonProps = ButtonElementProps;

// Variant styles
const VARIANT_CLASSES: Record<Variant, string> = {
  primary:
    "bg-primary text-primary-foreground hover:bg-primary-hover active:scale-[0.98]",
  outline:
    "bg-background text-primary border border-primary hover:bg-pink/30",
  ghost:
    "bg-transparent text-primary hover:bg-muted",
  social:
    "bg-background text-foreground border border-border hover:bg-muted",
};

// Size classes — both variants ≥ 48px touch target
const SIZE_CLASSES: Record<Size, string> = {
  md: "min-h-12 px-5 py-3.5 text-sm font-semibold",
  lg: "min-h-14 px-6 py-4 text-base font-semibold",
};

// Social provider tinting when variant=social
const SOCIAL_CLASSES: Record<SocialProvider, string> = {
  google: "",       // white button with Google icon
  apple: "bg-black text-white border-black hover:bg-zinc-800",
  facebook: "bg-[#1877F2] text-white border-[#1877F2] hover:opacity-90",
  whatsapp: "bg-[#25D366] text-white border-[#25D366] hover:opacity-90",
  email: "",        // same as default social
};

export function Button({
  as = "button",
  variant = "primary",
  size = "md",
  loading = false,
  iconLeft,
  iconRight,
  fullWidth = false,
  socialProvider,
  className,
  children,
  ...rest
}: ButtonProps) {
  const socialExtras = variant === "social" && socialProvider ? SOCIAL_CLASSES[socialProvider] : "";
  const classes = cn(
    "inline-flex items-center justify-center gap-2 rounded-lg transition-colors",
    "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2",
    "disabled:pointer-events-none disabled:opacity-50",
    VARIANT_CLASSES[variant],
    SIZE_CLASSES[size],
    socialExtras,
    fullWidth && "w-full",
    className,
  );

  const content = (
    <>
      {loading ? <Loader2 className="h-4 w-4 animate-spin" /> : iconLeft}
      {children}
      {!loading && iconRight}
    </>
  );

  if (as === "a") {
    return (
      <a className={classes} {...(rest as React.AnchorHTMLAttributes<HTMLAnchorElement>)}>
        {content}
      </a>
    );
  }

  return (
    <button
      type="button"
      className={classes}
      disabled={loading || (rest as React.ButtonHTMLAttributes<HTMLButtonElement>).disabled}
      {...(rest as React.ButtonHTMLAttributes<HTMLButtonElement>)}
    >
      {content}
    </button>
  );
}
```

Key points:
- `as: 'button' | 'a'` via discriminated union so `href` is only typed when `as="a"`.
- Social variant reuses base `social` styles + optional provider tint (Apple black, Facebook blue, WhatsApp green). Google/email stay on the default white with border.
- Loading replaces `iconLeft` with a spinning `Loader2` from lucide.
- `disabled` is auto-set when `loading` is true to prevent double-submits.
- Touch target: `min-h-12` (= 48px) on md, `min-h-14` (= 56px) on lg. `py-3.5` on md enforces the CLAUDE.md button minimum.
- Focus ring: keyboard-only via `focus-visible:`.
